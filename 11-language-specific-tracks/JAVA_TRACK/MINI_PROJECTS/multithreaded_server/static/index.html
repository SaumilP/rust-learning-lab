How It Works

When you requested this file, the server:

  1. Received your HTTP GET request
  2. Matched the path to the static file handler
  3. Read the file from disk
  4. Determined the Content-Type from the file extension
  5. Sent the HTTP response with the file contents
// Simplified static file handler in Rust
fn static_file_handler(path: &str) -> Response {
    let contents = fs::read_to_string(path)?;
    Response::new(StatusCode::OK)
        .content_type("text/html")
        .body(contents)
}
