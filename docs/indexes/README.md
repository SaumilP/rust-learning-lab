# Concept indexes

These indexes are a way to find the primary lesson for an idea without replacing the recommended learning path. Start with [From Zero: the canonical Rust path](../curriculum/from-zero.md) if you are new to Rust, then use an index when you need to revisit a concept or connect it to the next one.

Each link points to the repository's main lesson for that subject. Some concepts appear in more than one place because Rust ideas reinforce one another; the index identifies the best first stop and names useful follow-up lessons where that helps.

## Choose an index

- [Foundations](foundations.md) covers syntax, values, control flow, ownership, and the standard library essentials needed to read and write small Rust programs.
- [Types and program design](types-and-design.md) covers traits, generics, enums, pattern matching, lifetimes, and the choices that shape program interfaces.
- [Building and maintaining programs](building-programs.md) covers testing, debugging, documentation, command-line programs, files, and introductory concurrency.

These pages do not set a content status. Check [Content status](../../CONTENT_STATUS.md) when you need to know whether an area is Planned, Draft, Review, or Stable.
