# Traits and Polymorphism: Key Takeaways

- Traits define behavior shared by otherwise unrelated types.
- `impl Trait` is concise for a single trait-bounded parameter.
- `T: Trait` is useful when the generic type appears more than once.
- `dyn Trait` enables runtime polymorphism through indirection.
- A type can implement a trait only when either the type or trait is local.
