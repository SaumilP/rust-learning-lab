# Advanced Function and Type-System Review

This supplementary module revisits ownership, generics, traits, and enum-based
design in a compact form. It is useful as a review after
[`01-core-fundamentals`](../01-core-fundamentals/) and
[`02-standard-library`](../02-standard-library/).

For the main intermediate sequence—including modules, concurrency, async,
testing, and macros—continue with
[`06-intermediate-rust`](../06-intermediate-rust/).

Each topic contains a concept README and key takeaways. Read those notes, write
a small example from memory, and then compare it with the related material in
the main learning path.
