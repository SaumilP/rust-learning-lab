These optional deep dives revisit the main Module 06 concepts with larger examples. They are useful after the primary sequence, not as a replacement for it.

1. [Ownership and borrowing](ownership_and_borrowing/README.md) explores string manipulation.
2. [Traits and polymorphism](traits_and_polymorphism/README.md) builds a logger system.
3. [Generics](generics/README.md) develops reusable container operations.
4. [Enums and pattern matching](enums_and_pattern_matching/README.md) models a small JSON value tree.
5. [Exercises](exercises/) provides four additional review problems.

This material remains Draft and is intentionally excluded from the primary Module 06 `make check` target until it has its own validation coverage.
