# Will It Compile?

These challenges ask you to decide whether a short Rust program is accepted by the compiler before you run it. The useful part is the reasoning: identify ownership, borrowing, trait, lifetime, or type rules that apply, then explain the compiler’s decision in your own words.

The current questions are structured quiz items, not a second copy of the core lessons. Start with the `will_it_compile` items in [quiz-items/](../quiz-items/), reveal the answer only after making a prediction, and follow the item’s canonical lesson reference when you need a refresher.

When authoring one of these challenges, include the smallest complete code sample that demonstrates the rule. Validate both the expected compiler result and the explanation. A compilation failure should be intentional and should teach one primary idea rather than becoming a puzzle about unrelated syntax.
