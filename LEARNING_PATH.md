# Rust Learning Lab: Integrated Learning Path

Use the modules in numeric order; each stage applies concepts from the stages
before it.

| Stage | Modules | Outcome |
|---|---|---|
| Foundations | 00–03 | Write, compile, test, and document small Rust programs |
| Applications | 04–05 | Combine I/O, algorithms, state, and user interaction |
| Type system | 06 | Use ownership, traits, generics, enums, and lifetimes |
| Advanced Rust | 07–08 | Apply advanced features and design patterns |
| Projects | 09 | Build complete programs with multiple concerns |
| Production | 10 | Organize, measure, deploy, and operate Rust software |
| Transition guides | 11 | Map experience from Java, Python, Go, or C++ to Rust |

## Recommended workflow

1. Read the concept README and key takeaways.
2. Compile and modify every example.
3. Repair the deliberately broken exercise without reading hints first.
4. Run the module's `make check` target when available.
5. Apply the concept in a mini-project before moving to the next stage.

Generated `build/` and `target/` directories are disposable. Keep source,
exercise descriptions, and documentation under version control—not compiled
artifacts.
