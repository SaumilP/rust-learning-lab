# Code review challenges

These short reviews ask you to identify the most important issue in working or nearly working Rust, explain its learner-visible consequence, and suggest a proportionate improvement. They are not style quizzes: a good answer connects the code to correctness, ownership, error handling, or API design.

The items in [items/](./items/) use the validated quiz format with `type: "code_review"`. Make a review note before reading the stored answer, then use the canonical lesson reference to study the underlying rule.
