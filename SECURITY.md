# Security Policy

This repository contains educational examples and is not distributed as a
production service. Security issues can still matter, especially in examples
covering file handling, networking, unsafe Rust, FFI, or dependencies.

## Reporting a vulnerability

Please report a suspected vulnerability privately through GitHub's private
vulnerability reporting feature when it is available for this repository. If
that feature is unavailable, contact the maintainer privately using the contact
method on the maintainer's GitHub profile.

Include the affected path, the impact, steps to reproduce the issue, and a
suggested fix if you have one. Do not include secrets or personal data in the
report.

Please do not open a public issue until the maintainer has assessed the report.
You should receive an acknowledgement within seven days. Because this is a
volunteer learning project, remediation timelines depend on severity and
maintainer availability.

## Supported versions

Only the current default branch is maintained. Historical revisions and forks
are not covered by this policy.
