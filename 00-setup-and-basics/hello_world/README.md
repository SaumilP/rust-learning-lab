# Hello, world!

This first program introduces the shape of a Rust binary: the `main` function, the `println!` macro, variables, and formatting values in output.

Run it from this directory with `cargo run`. Then change the `audience`, `language`, or `numbers` values and run it again to see how Rust formats each value.

## What to notice

- Every executable Rust program starts at `fn main()`.
- `println!` is a macro, which is why its name ends with `!`.
- `{}` formats a value for display, while `{:?}` shows its debug representation.
