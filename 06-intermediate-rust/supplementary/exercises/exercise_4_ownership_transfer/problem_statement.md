# Exercise 4: Fix Borrow Checker Errors

## Difficulty: Hard
## Concepts Tested: Ownership, Borrowing, Lifetimes
## Prerequisites: Module 06 concepts

## Problem Statement

Fix code that has borrow checker violations:

1. Fixing moved value usage
2. Fixing multiple mutable borrows
3. Fixing dangling references
4. Using proper ownership patterns
5. Understand when to use references vs ownership transfer

## Requirements

- Identify 3 borrow checker errors
- Fix using ownership rules
- Use references appropriately
- Apply lifetime patterns where needed
- Maintain functionality while satisfying compiler
