# HTTP Client

Production HTTP client examples using `reqwest` for modern async HTTP operations.

## Features

- GET/POST/PUT/DELETE requests
- JSON serialization/deserialization
- Custom headers and authentication
- Request timeout handling
- Connection pooling
- Error handling

## Running

```bash
cargo run
```

## What You'll Learn

- Using `reqwest` for HTTP requests
- JSON handling with `serde`
- Async HTTP patterns
- Client configuration
- Error handling strategies
- Bearer token authentication
- Custom headers
