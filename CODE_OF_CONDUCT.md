# Code of Conduct

Rust Learning Lab is intended to be a constructive place to learn and improve
technical material. Participants are expected to treat one another with
patience, respect, and professional courtesy.

## Expected behaviour

- Give feedback about the work, not the person.
- Assume questions are asked in good faith.
- Welcome learners with different backgrounds and levels of experience.
- Explain technical disagreements with evidence and reproducible examples.
- Respect privacy and avoid sharing another person's personal information.

Harassment, discriminatory language, personal attacks, threats, sustained
disruption, and unwanted sexual attention are not acceptable.

## Reporting

If you experience or observe unacceptable behaviour, contact the repository
maintainer privately using the contact method on the maintainer's GitHub
profile. Do not open a public issue that identifies the people involved.

Reports will be reviewed as promptly and impartially as possible. Maintainers
may edit or remove contributions, issue a warning, temporarily restrict
participation, or permanently ban a participant when needed to protect the
community.

This policy applies in repository discussions, issues, pull requests, and other
spaces where someone is representing the project.
